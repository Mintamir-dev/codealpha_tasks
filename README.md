## Task 1: Project Management Tool

A team project management app: create projects, invite members by email, track tasks on a
Kanban board (To Do, In Progress, Done, Blocked), comment with @mentions, and get
real-time notifications.

Live demo: https://pm-tool-web-tyud.onrender.com
(Free hosting: the first load can take about a minute while the server wakes up.
You can create your own account with "Create account".)

Stack: React, Vite, Tailwind CSS, Node.js, Express, Socket.IO, PostgreSQL (Neon), Render.

To run it locally, see the README files inside the backend and frontend folders.
